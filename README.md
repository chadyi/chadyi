# chadyi

Student building AI tools around LLM agents, open-source automation, and local-first developer workflows.

I am interested in making AI systems easier to test, compare, and use in real workflows: agent simulations, search-augmented APIs, and practical developer tooling.

## Featured open-source work

### chadyi/AITradeGame

MIT-licensed AI trading simulator with 900 stars, local and online versions, OpenAI-compatible model support, realistic fees, leaderboards, and privacy-preserving local storage.

### chadyi/Search-for-LLMAPI

Lightweight service that adds live web search to LLM APIs so model responses can stay fresher and more grounded.

### chadyi/token-viewer

Local-first desktop app for analyzing token usage and AI costs from Claude Code, Codex CLI, and OpenCode logs.

## Current interests

LLM agents, evaluation, developer automation, AI-assisted code review, and tools that help maintainers ship safer open-source software.
